Fonts used by the document system (src/lib/documents).

NotoNaskhArabic-Regular.ttf
NotoNaskhArabic-Bold.ttf

  (https://github.com/notofonts/arabic).

  This Font Software is licensed under the SIL Open Font License, Version 1.1.
  The license and its FAQ are available at https://openfontlicense.org

  Used so that Urdu (and Arabic, Persian, Sindhi, Pashto) names and text print
  correctly in generated PDFs. It covers every Urdu letter, the presentation
  forms the PDF engine uses for joining, and the full Latin range.

  Served from the app's own origin so documents render identically offline and
  on a school's own network. Do not replace with WOFF/WOFF2: the PDF engine only
  embeds TrueType.
